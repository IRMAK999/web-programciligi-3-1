# Kampüs Yazılım Kulübü - Örnek Web Projesi

HTML ve CSS ile hazırlanmış, iki sayfalık küçük bir kulüp tanıtım sitesidir. Web Programcılığı III dersi Hafta 1 uygulama ödevidir.

## Sayfalar
- index.html: Ana sayfa
- iletisim.html: İletişim formu
- style.css: Stil dosyası



## Özellikler
- Menü ile sayfalar arası geçiş
- Mobil uyumlu (responsive) tasarım
- İletişim formu (sadece arayüz)
